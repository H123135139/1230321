# 此处三物

此处三物，从根到叶：

- **根 · 不易** —— `01-不易·碑`：吉元节律 · 安居常余指引。万变中不变的几条——拿走就能用，不用学。
- **干 · 简易** —— `02-简易·钥`：问一题 · 回溯三问 · 随身地图。一把需要你自己打的钥匙——照着问，自己打。
- **叶 · 变易** —— `03-变易·场`：玩棋问妙 · 动力金字塔。每一局棋的新鲜玩法——放下来，就是你的。

碑风蚀，人立安。钥棋妙，心在乐。场幻变，律守道。

根目录另有《总钥匙》——三十秒看懂全部。

拿走你需要的部分，其余随风。
